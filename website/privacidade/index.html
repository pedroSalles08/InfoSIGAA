Política de privacidade

01 · Website

Dados no website

O website do InfoSIGAA é estático. O projeto não utiliza formulários, contas, cookies próprios, analytics, pixels de rastreamento, fontes externas ou scripts de terceiros para coletar informações dos visitantes.

O website será hospedado pelo GitHub Pages. Como provedor de hospedagem, o GitHub pode processar dados técnicos de conexão, como endereço IP e registros de acesso, de acordo com seus próprios termos e política de privacidade. Esses registros não são recebidos nem usados pelo InfoSIGAA para criar perfis de visitantes.

02 · Extensão

Como a extensão funciona

A extensão funciona apenas quando você já está autenticado no SIGAA do IFFarroupilha. Ela usa a sessão existente no navegador para acessar as páginas necessárias, organizar matérias, notas e frequência e exibir essas informações no popup do InfoSIGAA.

  • Não faz login automaticamente.
  • Não solicita, lê ou armazena sua senha.
  • Não salva cookies manualmente.
  • Não envia notas, frequência ou identificação do estudante para servidor externo do projeto.
  • Não executa verificações automáticas em segundo plano.

03 · Extensão

Permissões utilizadas

activeTab

Permite interagir com a aba ativa quando você inicia uma atualização.

scripting

Permite ler o conteúdo necessário da página ativa do SIGAA para iniciar a coleta.

storage

Permite manter localmente o último painel válido e comparar alterações entre atualizações.

sig.iffarroupilha.edu.br

Limita o acesso de rede da extensão às páginas do SIGAA do IFFarroupilha.

04 · Extensão

Armazenamento e controle

O último resultado válido é armazenado em chrome.storage.local, dentro do perfil do Chrome. Esse conteúdo não é sincronizado entre computadores ou perfis e normalmente é removido quando a extensão é desinstalada.

Em um computador compartilhado, outra pessoa com acesso ao mesmo perfil do Chrome pode abrir o popup e visualizar o último painel salvo. Use um perfil individual e remova a extensão quando não quiser manter esses dados no dispositivo.

Quando uma sessão expira ou uma atualização falha por completo, o InfoSIGAA preserva o último resultado válido em vez de substituí-lo por dados incompletos.

05 · Política

Alterações nesta política

Esta política poderá ser atualizada quando o comportamento do website, da extensão ou de sua distribuição mudar. A data da revisão mais recente será mantida no início desta página.
